격자 사각형 인접 및 Union-Find 알고리즘 최적화 노트

1. 반개방 구간 (Half-Open Interval) 좌표계 모델링

2차원 격자에서 사각형 좌표 $(x_1, y_1) \sim (x_2, y_2)$를 처리할 때 사용하는 표준 기하학 모델입니다.

  • 수학적 정의: $x$축 $[x_1, x_2)$, $y$축 $[y_1, y_2)$ 범위 사용 (시작점 포함, 끝점 미포함 경계선).
  • 차지하는 격자 셀 범위: $x_1 \le x < x_2$, $y_1 \le y < y_2$
  • 기하학적 면적 계산: $\text{Width} = x_2 - x_1$, $\text{Height} = y_2 - y_1$, $\text{Area} = \text{Width} \times \text{Height}$

특수 입역 케이스 예시

입력 좌표 예시 도형 형태 및 점유 셀 면적 (Area) 비고
(0, 0), (4, 0) 두께 없는 직선 (선분) $4 \times 0 = 0$ $y_1 = y_2$로 $y$축 길이가 0이며 셀을 점유하지 않음.
(0, 0), (4, 1) 가로 4칸 1행 사각형 $4 \times 1 = 4$ m[0][0]~[0][3] 총 4개 셀 점유.
(2, 1), (3, 5) 세로 4칸 1열 사각형 $1 \times 4 = 4$ m[1][2]~[4][2] 총 4개 셀 점유.
(2, 3), (3, 4) 단일 $1 \times 1$ 셀 $1 \times 1 = 1$ m[3][2] 단 1개 셀 점유.

2. 접근 방식별 공간/시간 복잡도 비교 ($K=8,000$, $8,000 \times 8,000$ 격자)

방식 A: 2차원 배열 m[8000][8000] 테두리 탐색 방식

  • 원리: 내 테두리 바깥 1칸 궤적을 2차원 배열에서 읽어 인접 사각형을 탐색 후, 내 테두리만 배열에 기록.
  • 연산량: 사각형당 둘레 길이 $2 \times (W + H) = 2 \times (8000 + 8000) = 32,000$회
  • 메모리: $8000 \times 8000 \times 4\text{ Bytes} \approx \mathbf{256\text{ MB}}$ (메모리 제한 초과 위험)

방식 B: $O(1)$ 기하학적 1:1 구간 비교 방식 (선택)

  • 원리: vector<Cell>에 보관된 기존 $K$개 사각형과 기하학적 $1:1$ 접촉 길이 연산 수행.
  • 총 연산 횟수: $_NC_2 = \frac{8000 \times 7999}{2} \approx \mathbf{3,200\text{만 회}}$ ($\approx \mathbf{0.03\text{초}}$ 소요)
  • 메모리: 8,000개 구조체 저장 $\approx \mathbf{128\text{ KB}}$ (매우 안전)

3. 1:1 접촉 연산 및 삼항 연산자 / std::max 축약

축 경계선 일치 조건

  • y1 == rect.y2 || y2 == rect.y1 : 위/아래 방향으로 면을 접함 ($x$축 겹침 길이 산출)
  • x1 == rect.x2 || x2 == rect.x1 : 좌/우 방향으로 면을 접함 ($y$축 겹침 길이 산출)

구간 겹침 길이 계산 및 삼항 연산자 표현 개선

두 구간 $[A_{1}, A_{2}]$와 $[B_{1}, B_{2}]$의 겹침 길이는 $\min(A_{2}, B_{2}) - \max(A_{1}, B_{1})$ 입니다.

삼항 연산자 변환:

int len = min(rect.x2, x2) - max(rect.x1, x1);
l += (len > 0) ? len : 0;

std::max를 활용한 1줄 최적화:

l += max(0, min(rect.x2, x2) - max(rect.x1, x1));

4. 디버깅 및 코드 교정 포인트 종합

❌ 교정 1: if (len) l += len; 음수 가산 버그
C++에서 음수도 `true`로 처리되므로 두 사각형이 떨어져 있을 때 음수가 합산되는 오류 발생.
👉 해결: `max(0, ...)` 패턴을 도입하여 0 미만 값을 차단함.
❌ 교정 2: unionSet 내부 `find()` 중복 호출
`unionSet(u, v)` 구현체 내부에서 루트 노드 조회를 수행하므로 외부에서 `unionSet(cellId, find(rect.id))`처럼 전달할 필요 없음.
👉 해결: `unionSet(cellId, rect.id);`로 직접 ID 전달.

5. 최종 완성 C++ 최적화 코드

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

struct Cell {
    int id;
    int x1, y1, x2, y2;
    int area;
};

vector<Cell> cell;
int L = 2; // 그룹 병합 최소 접촉 길이

int parent[8005];

int findSet(int u) {
    if (u == parent[u]) return u;
    return parent[u] = findSet(parent[u]);
}

void unionSet(int u, int v) {
    int rootU = findSet(u);
    int rootV = findSet(v);
    if (rootU != rootV) parent[rootU] = rootV;
}

int addCell(int cellId, int x1, int y1, int x2, int y2) {
    int size = (x2 - x1) * (y2 - y1);
    
    // 기존 사각형들과 1:1 접촉 검사
    for (auto &rect : cell) {
        int l = 0;
        
        // 1. 위/아래면 접합부 (y축 경계 일치 -> x축 겹침 길이)
        if (y1 == rect.y2 || y2 == rect.y1) {
            l += max(0, min(rect.x2, x2) - max(rect.x1, x1));
        }
        
        // 2. 좌/우면 접합부 (x축 경계 일치 -> y축 겹침 길이)
        if (x1 == rect.x2 || x2 == rect.x1) {
            l += max(0, min(rect.y2, y2) - max(rect.y1, y1));
        }
                
        // 3. 접촉 길이가 L 이상이면 Union-Find 그룹 병합
        if (l >= L) {
            unionSet(cellId, rect.id);
        }
    }    
    
    // 검사 완료 후 목록 추가
    cell.push_back({ cellId, x1, y1, x2, y2, size });

    return 0;
}

6. 환경 및 메모리 할당 주의사항

  • 스택 메모리 제한: 제한 크기가 1MB~8MB로 매우 작음.
  • 전역 변수 활용: $100 \times 100$을 초과하는 배열이나 대형 객체는 지역 변수(스택)가 아닌 전역 변수(BSS/Data 영역)로 선언하여 스택 오버플로우를 방지할 것.
