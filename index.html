알고리즘 복습 노트: 격자 사각형 및 접촉 판정

1. 반개방 구간 모델 (Half-Open Interval)

알고리즘 문제 및 표준 라이브러리에서 직사각형 영역을 정의할 때 주로 사용하는 좌표 체계입니다.

  • 표현 방식: 좌상단 $(x_1, y_1)$ ~ 우하단 $(x_2, y_2)$
  • 실제 차지하는 셀 범위: $x_1 \le x < x_2$, $y_1 \le y < y_2$
  • 핵심 특징: 우하단 끝점 $(x_2, y_2)$ 좌표 자체는 **포함하지 않는 경계선(Vertex)** 역할을 함.
형태 좌표 예시 실제 차지하는 격자 셀 ($m[y][x]$) 크기 계산 formula
1행 사각형 (세로 1칸) (0, 0) ~ (3, 1) m[0][0], m[0][1], m[0][2] (총 3칸) $(3 - 0) \times (1 - 0) = 3$
1열 사각형 (가로 1칸) (2, 1) ~ (3, 5) m[1][2], m[2][2], m[3][2], m[4][2] (총 4칸) $(3 - 2) \times (5 - 1) = 4$
1x1 사각형 (2, 3) ~ (3, 4) m[3][2] (총 1칸) $(3 - 2) \times (4 - 3) = 1$

2. 기존 테두리 배열 채우기 방식의 문제점 및 해결책

기존 코드 버그 원인

  • 주석과 좌표 축 불일치: $x$축과 $y$축 인덱스가 바뀌어 테두리가 엇갈려 칠해짐.
  • 역방향 루프 조건 오류: for(int x = x2 - 1; x <= x1; x--)와 같이 감소 루프에서 조건식을 <=로 설정하여 무한 루프 또는 오작동 발생 (올바른 식: x >= x1).
  • Read/Write 충돌: 테두리를 칠하는 도중 자기 자신의 미처 채우지 않은 칸을 외부 인접 셀로 오인하는 문제.
해결책: 배열을 칠하기(Write) 전에 외각 1칸 궤적을 먼저 검사(Read)한 뒤, 테두리를 정방향(++)으로만 칠하면 순서나 예외 처리 문제에서 완전히 자유로워짐.

3. O(1) 기하학적 구간 겹침 알고리즘 (추천 대안)

2차원 배열 $m[][]$에 테두리를 일일이 그리지 않고, 좌표 비교만으로 두 사각형이 맞닿은 변의 길이를 즉시 구하는 방식입니다. ($K=8,000$개일 때 전체 비교 횟수 약 640만 번으로 수십 ms 내 수행 가능)

① 축 일치 판별 조건 ( 등가 비교 )

두 사각형 $A, B$의 경계선 좌표 하나가 완벽히 일치해야 상/하/좌/우로 붙어있을 수 있습니다.

  • A.y2 == B.y1 : A의 아래쪽 변과 B의 위쪽 변이 붙음
  • A.y1 == B.y2 : A의 위쪽 변과 B의 아래쪽 변이 붙음
  • A.x2 == B.x1 : A의 오른쪽 변과 B의 왼쪽 변이 붙음
  • A.x1 == B.x2 : A의 왼쪽 변과 B의 오른쪽 변이 붙음

② 구간 겹침 길이 계산 공식

축이 일치할 때, 나머지 방향 구간 $[A_{start}, A_{end}]$와 $[B_{start}, B_{end}]$의 겹침 길이는 아래와 같습니다.

$$\text{Overlapping Length} = \min(A_{end}, B_{end}) - \max(A_{start}, B_{start})$$ * 이 값이 양수($> 0$)일 때만 해당 길이만큼 면을 접하고 있는 것임.

최종 C++ 구현 코드

struct Cell {
    int x1, y1, x2, y2;
};

// 두 사각형 A와 B가 접해 있는 변의 총 길이를 계산하는 함수
int getContactLength(const Cell& A, const Cell& B) {
    int totalLen = 0;

    // 1. 위/아래로 맞닿은 경우 (y축 경계선 일치) -> x축 겹침 계산
    if (A.y2 == B.y1 || A.y1 == B.y2) {
        int overlapX = min(A.x2, B.x2) - max(A.x1, B.x1);
        if (overlapX > 0) totalLen += overlapX;
    }

    // 2. 좌/우로 맞닿은 경우 (x축 경계선 일치) -> y축 겹침 계산
    if (A.x2 == B.x1 || A.x1 == B.x2) {
        int overlapY = min(A.y2, B.y2) - max(A.y1, B.y1);
        if (overlapY > 0) totalLen += overlapY;
    }

    return totalLen; // 0이면 닿지 않음, >0 이면 닿은 길이
}
